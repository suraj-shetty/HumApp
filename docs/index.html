Liquid Glass, one file deep

The tab bar and player bar sit in a single GlassEffectContainer and share one glassEffectID, so the bar doesn't fade into Now Playing — it morphs into it. Every .glassEffect() call in the app funnels through one file, enforced by a build-failing containment script.

2

Your library, not a catalog demo

Home, Library, Search, Detail, Now Playing and Queue all run on real MusicKit data — your recently played, your playlists, your albums — through Apple's own playback engine. Hum never streams anything itself.

3

Built the boring, correct way

Swift 6 strict concurrency from the first commit, warnings treated as errors, reducers unit-tested in isolation from any UI, and an architecture script that fails the build if a feature screen imports MusicKit directly.

Six screens

Home, Library, Detail, Now Playing, Search

Captured on-device against a real Apple Music library — real playlists, real artwork slots, real durations. The design's overline-and-amber language (RECENTLY PLAYED, MADE FOR YOU) carries through every screen without a single hard-coded fixture.

Queue, Settings, Connect

The parts most apps skip polishing

An Up Next sheet with a live playing indicator, a Settings screen that states plainly what Hum does and doesn't do, and an onboarding screen that asks for Apple Music access with the actual permission scope spelled out — not a generic "Continue".

Designed and built here

One design, enforced by the build

The "Amber Glow" design system was extracted value-for-value from the project's own HTML prototype — colors, type ramp, spacing, motion timings — then reconciled against the shipped SwiftUI so the two never drift apart silently.

Swift 6, strict
Concurrency checking set to complete from the first commit, with per-layer isolation — reducers are pure nonisolated structs, MusicKit adapters are actors.
Architecture enforced, not documented
A pre-build script greps the tree and fails the build if a feature screen imports MusicKit, or if .glassEffect() appears outside the one file that owns it.
50+ unit tests
Auth, subscription-gating and queue reducers tested as pure logic, entirely independent of MusicKit, the network, or a device.
